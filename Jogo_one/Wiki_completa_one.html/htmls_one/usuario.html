O usuário poderá escolher uma dessas classes para jogar o jogo. Cada classe com suas especialidades e designs únicos

Classes do Usuario

→ Algumas das classes que haverão no jogo:

  • Cavaleiro
  • Assassino
  • Arqueiro
  • Mago

→ Após zerar a primeira campanha:

  • Berserker
  • Monge
  • Invocador
  • Bardo

Requisitos para desbloquear classes

  • Berserker: Requer que o jogador complete todo o bestiario, sendo assim. Matar toda e qualquer criatura do jogo
  • Monge : Requer que o jogador finalize o jogo sem matar qualquer inimigo (exceto aqueles que são obrigatorios para o avanço do game)
  • Bardo : Encontre todos os musicos em cada região do jogo
  • Invocador : Tenha todas as classes do jogo
💡

O usuario pode acabar conseguindo um buff ou um debuf dependendo da arma que ele for utilizar, se ela é ou não compativél com a classe escolhida

Niveis

Cada classes haverão especialidades, algumas serão mais resistentes, outras mais rápidas, cada um com sua peculiaridade, e essas peculiaridades irão fortalecer ou ajudar o usuário dependendo da arma ou item que deseja utilizar.

Cada um terá um nível de pericia com tais tipos de armas, e esses níveis de pericias são:

    Maior → São armas que o usuário consegue +50% de dano a mais usando elas

    Medio → São armas que o usuário consegue +25% de dano usando elas

    Normal → São armas que o usuário não tem nenhum buff ou debuff

    Baixo → São armas que o usuário tem -30% de dano ou +30% de lentidão utilizando elas
